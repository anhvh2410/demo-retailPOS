# Retail POS: bản demo

Bản chạy thử hệ thống bán hàng rút gọn cho cửa hàng bán lẻ, dùng dữ liệu mẫu ngay trên trình duyệt (không cần máy chủ, không cần cài đặt).

Gồm: bán hàng tại quầy (tiền mặt, VietQR), sản phẩm, tồn kho, đơn hàng, báo cáo doanh thu, nhân viên và phân quyền, khuyến mãi, kết nối kênh online (mô phỏng Shopee, TikTok Shop, Lazada), cài đặt cửa hàng.

Dữ liệu lưu trong trình duyệt của người xem; muốn về trạng thái ban đầu thì xóa dữ liệu trang web.
